# Changelog

## 2.0.0-dev.1

- 使用 Dart 3.3 extension type 提供无额外包装对象的 `.axc` 命名空间。
- 修复 List/Map 泛型丢失；命名空间表示值不再允许重新赋值。
- 按标准 package 结构拆分 `lib/src` 实现与公开导出。
- 补齐集合查改、分块、去重、稳定排序；所有集合改动返回浅拷贝。
- 字符串截取统一为字素簇；修复递归截取、错误替换对象、区间终点和空标记循环问题。
- 增加数值区间、舍入、日期、URI、编码、摘要、类型化关联值及同步 once。
- 提供独立的 `axc_bedrock_flutter` 包，包含几何、Insets、颜色、字体和原生图片提供者入口。
- 增加边界测试、编译期正反例、共享 Swift/Dart 行为用例、Web 编译检查和最低版/稳定版 CI。
- 本版不兼容 1.0.0 原型 API，迁移说明见 `doc/migration.md`；尚未发布到 pub.dev。

## 1.0.0

- 初始 Dart 命名空间原型，包含字符串、集合、数值和区间工具。
